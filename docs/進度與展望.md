## 一、這個東西現在能做什麼

一句話：**本機執行的 AI 用量儀表板，盯配額、順便算「訂閱費回本幾倍」。**

免錢、不用裝套件、不連外部服務（除了跟各家官方要自己的用量數字）。
可以開瀏覽器完整版，也可以當桌面置頂小浮窗常駐。

目前盯得到三家：

| 提供商 | 盯得到什麼 | 前提 |
|---|---|---|
| **Claude** | 5 小時 session、每週配額、本機對話的 context 剩餘量 | 本機 Claude 憑證有效 |
| **Codex** | session、每週配額、本機對話 context | 已登入 Codex CLI |
| **Antigravity** | 兩條週配額（Gemini 組 / Claude+GPT 組） | **Antigravity IDE 要開著** |

外加一張 🐑 **薅羊毛進度表**：把你在 Claude Code 做過的事，換算成「同樣的活兒改打 API 要付多少」，
拿去跟訂閱月費比，算回本倍率。

## 三、進行中 / 卡點

### 🔴 Claude 卡目前是降級狀態（需要裁決）

**現況**：2026-09-17 實測，Claude 那張卡顯示紅字「自動失敗，退回手動」。
原因是本機憑證檔 `~/.claude/.credentials.json` 裡的 Claude 授權
**已於 2026-09-16 23:13 過期**，儀表板讀到過期就不再往下打 API。

影響：Claude 的 session / 每週血條變成手動值，不會自己更新。
（薅羊毛表**不受影響**——它掃的是本機對話記錄，不需要授權。）

**還沒確認的是**：那個憑證檔該由誰刷新。儀表板目前的提示寫「執行任一 claude 指令讓它自動刷新」，
這是針對命令列版寫的；老師現在用的是桌面版，是否也會刷新同一個檔案**尚未驗證**。

可能的處理方向（**都還沒做，等老師決定**）：

1. 什麼都不改，過期時就手動去跑一次命令列版讓它刷新。
2. 讓儀表板自己拿檔案裡的 refresh token 去續期——**會動到授權流程，風險較高**，需要老師點頭。
3. 只改提示文字，讓它不要斷言「跑 claude 指令就會好」。

### ⚪ 已由老師關閉

- **「Antigravity 數字對不上」**：2026-09-17 老師回報過，後續確認可以了（回覆「我看到了！ok」）。
  過程中順手排除了一個可能成因（本機資料被快取 3 分鐘，已改成 20 秒）。
  **實際成因沒有查明**，若日後再發生需要重新調查。

## 五、長期構想

> ⚠️ 以下**只是構想，都還沒承諾、也還沒排期**。

- **多帳號切換**：最初的規格書留了擴充位，各帳號各自快照。目前薅羊毛表是多帳號混在一起算的。
- **歷史趨勢**：現在只看得到「當下」的配額與本期累積，沒有跨週/跨月的曲線。
  資料其實都在本機掃描快取裡，要做得出來。
- **更多提供商**：架構上加一家就是寫一個 `fetchXxx()`。Gemini CLI、Cursor 之類都是候選。
- **跨平台**：目前浮窗與行程偵測都是 Windows 專用；macOS / Linux 的分支有寫但**從未實機測過**。

## 六、一個要記得的風險

這個工具讀的全都是**各家沒有公開承諾的內部端點**。它們隨時可能改格式或改驗證方式，
改了這邊就讀不到——**v0.8.1 修的 Antigravity 就是活生生的例子**
（上游某天開始要求一個額外的驗證 token，整個功能直接啞掉，而且不會有人來通知）。

程式已經寫成「讀不到就顯示讀不到、沿用舊資料，不會整個崩掉」，
所以最糟的情況是某張卡變空白，不是儀表板掛掉。看到某家突然讀不到，先想這個可能。
